# Recommendo

A phone recommendation form that turns your budget and priorities into a shortlist.

**[Open the live site](https://ajeet-iitk.github.io/smartphone-recommendor/)**

![Recommendo screenshot](screenshots/website.jpg)

## What it does

Answer a short set of questions - budget, what you care about, how you use the phone - and get a shorter list of candidates instead of a spec sheet wall.

## Features

- Multi-field preference form
- Static, client-side only: no accounts, no backend
- Bootstrap layout with custom SCSS sources in `scss/`

## Run locally

Open `index.html`, or use the hosted copy:

<https://ajeet-iitk.github.io/smartphone-recommendor/>
